Frequently asked questions

How many people can I enter?
2 to 500 people, one per line. The raw list can contain up to 60,000 UTF-16 character units. Each name, after trimming its edges, can contain up to 100 units; a typical emoji counts as 2 units.
Are duplicate names merged?
No. Each nonblank input line has its own ID, such as “Alex (#2)” and “Alex (#5)”. Check that these lines represent separate participants.
Will every group have the same size?
As close as possible. If the total does not divide evenly, the first few groups each receive one extra person, so sizes differ by at most one.
Is this a witnessed or auditable drawing?
No. The tool uses the browser’s cryptographic random API and unbiased sampling, but provides no seed, outside witness or reproducible audit proof. Consecutive results may be the same.
Is the list uploaded or saved?
The tool code does not send or save the list. Closing or leaving the page clears the current work. Loading the site still requests page files from the host, which receives ordinary request information. Clearing the page does not clear text you have already copied to the system clipboard.
What if the copy button does not work?
You can still select the results on the page. If the browser denies clipboard writing, the tool provides read-only text for manual copying.
