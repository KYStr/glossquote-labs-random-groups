貼上每行一人的名單，選擇組數，讓每位參與者剛好分到一組。

名單只在此頁面記憶體處理；不會保存或送出。

2–500 人。空白行會忽略。

同名會視為不同的人，結果會附上序號。請確認每一列代表一位參與者。

使用說明

將活動或課程名單分成指定組數，檢查每組完整成員與人數；重新分組前保留原名單，任何輸入改動都會清除舊結果。

先貼名單，再選組數並按「產生分組」。每組人數最多差一人。結果可直接選取，或由你按「複製分組」。

常見問題

我可以貼上多少人？
2 至 500 人；每人一行。原始名單最多 60,000 UTF-16 字元單位，姓名去除首尾空白後最多 100 單位；一般 emoji 佔 2 單位。
同名的人會合併嗎？
不會。每個非空輸入列都有獨立序號，例如「小明（#2）」和「小明（#5）」。請確認這些列確實代表不同參與者。
每組人數會完全相同嗎？
盡可能平均；不能整除時，前幾組各多一人，所以最多相差一人。
結果是可以公證或稽核的抽籤嗎？
不是。工具使用瀏覽器密碼學亂數 API 和無偏取樣程式，但不提供種子、外部見證或可重現稽核證明，也不保證連續結果不同。
名單會上傳或保存嗎？
工具程式不傳送也不保存名單，關閉或離開頁面會清除目前工作。載入網站仍會向託管主機請求頁面檔案，主機會收到一般請求資訊。清除頁面不會清除你已複製到系統剪貼簿的文字。
複製按鈕不能用怎麼辦？
結果仍可在頁面選取；瀏覽器拒絕剪貼簿寫入時，工具提供唯讀文字供你手動複製。
