# GlossQuote 品牌與名單隨機分組

品牌是 GlossQuote，產品家族是 Gloss Tools by GlossQuote。這款工具的核心工作是把既有名單依指定組數洗牌並平均分組。首屏直接讓人貼名單、選組數、產生結果；不做抽象 hero、SaaS 儀表板或假活動紀錄。

用字要說明「一行一人」「空行忽略」「同名保留並帶序號」「人數盡量平均」。同名只代表兩個輸入列，不能自行推斷真的是兩個不同的人，因此請使用者確認。不要把工具宣稱成公證抽籤、絕對公平或每次必定不同。

只使用能被程式與實際驗收支持的陳述。對資料處理如實說明目前頁面記憶體，不保存或傳送名單；同時承認瀏覽網站會連到靜態託管主機。不可承諾永久免費、所有瀏覽器相容或搜尋排名。

沿用 `DESIGN-SYSTEM.md` 的家族 tokens；使用本機系統 fallback 字型，不下載遠端字型、圖示或裝飾圖片。中英文頁各提供同語首頁入口，保持 GlossQuote 標識安靜。
